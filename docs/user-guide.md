# ModynToolbox 使用说明

## 打开与日常操作

完整便携目录中双击 ModynToolbox.exe。项目开发目录中双击 Open-ModynToolbox.cmd 可打开最近发布版。保留同级 app、tools、data。便携运行不要求安装 Python。

在左侧搜索并选择工具，主区显示该工具的输入、参数和处理按钮。工具较多时显示分类筛选。搜索支持工具名称、描述、分类和关键词。

每个工具右侧的 ＋ 新建一份空白会话，原会话继续保留。单会话时左侧紧凑显示，创建第二份后展开树形分支。点击分支切换，父工具名称回到最近使用的会话。Ctrl+N 可在左侧为当前工具新建会话。折叠展开状态会保存。

右键工具或会话，管理重命名、并排、保存草稿、独立窗口、收回和关闭。按住名称拖动，移到主窗口外松开会成为独立窗口。拖父工具时移出最近选中的会话。Esc 或在主窗口内松开取消拖出。浮窗关闭按钮收回会话，左侧 ↗ 表示它在独立窗口中，点击可唤起。

软件名称和说明分两行显示在顶部，浮窗第二行显示工具与会话名。主工作区集中显示工具输入、参数、动作和结果。

## 四个工具

| 工具 | 用途和规则 |
|---|---|
| JSON | 校验与格式化 UTF-8 文本，最多 5 MiB，保留数字、字符串转义和重复键的原始标记。错误给出定位，重复键给警告。 |
| 图片压缩 | 静态 JPEG/PNG/WebP，默认 WebP 质量 80，最长边 0 表示保持尺寸，避免放大。PNG 无损，透明图转 JPEG 用白底，应用 EXIF 方向并移除元数据。最多 500 张，单图 50 MiB、4000 万像素。 |
| 批量重命名 | 先预览，再确认执行，支持前后缀和编号规则。输入或规则变化后重新预览。可尝试撤销最近成功批次，异常中断后明确执行恢复。最多 2000 个文件。 |
| 文件校验 | C++ 独立工具，分块计算 SHA-256 / SHA-512，最多 2000 个文件，结果可复制或导出，支持取消。 |

图片输出目录留空时存到 data/tools/image/exports，指定目录时存到该目录。已有文件会使用编号区分。取消保留已经完成的输出。源图保持原样。

重命名处理期间不要删除工具数据中的计划和 journal。源身份、内容或目标变化可能导致拒绝执行或撤销，应先查看逐项结果和恢复记录。

文本超过 32768 个 UTF-16 码元时，界面显示只读预览并提示。完整数据仍保留，用于处理、复制和导出。要编辑大文件，可在外部编辑后重新载入。JSON 输入上限仍为 5 MiB。

结果导出在后台执行，采用临时文件原子提交。确认覆盖已有导出文件后才保存。可以通过运行记录查看状态，提交期间等待完成。

## 运行记录与设置

顶部活动入口只在运行、排队或存在未读失败记录时显示。管理菜单始终可以打开运行记录，查看动作、会话、状态、计数、输出位置或取消仍可取消的作业。记录最多保留最近 500 项摘要。

管理菜单的设置包含字体大小、界面密度、重批处理并发数、新会话默认保存草稿及处理结束后定位结果。默认全局最多两份作业、重批处理一份，同工具串行执行。重批处理可调整为两份，应结合本机内存使用。

## 安装、升级和删除工具

在“管理 → 工具包”选择包含 manifest.json 的完整工具包目录。安装会校验包内容与接入规范。新会话使用最新版本，已有会话固定原版本。

移除前关闭引用该版本的会话并等待作业结束。移除工具程序保留 data/tools/<tool_id> 中的数据。退出软件后，也可直接删除 tools/<tool_id> 的程序文件夹，下次启动撤下入口。运行时手动删除的缺失包可刷新识别，原会话输入继续保留，重新安装相同版本后可继续。

仅安装自己认可来源的本地工具。工具具有当前用户系统权限，文件摘要用于检查内容完整性。

## 草稿、数据和迁移

默认保存参数与布局。左侧会话右键菜单勾选“保存本会话输入草稿”后，正文和文件列表才进入 data/host/state.sqlite。新会话默认值可以在设置中调整。恢复不自动执行作业。文件缺失会保留引用并提示，可移除缺失项后重新添加正确路径。无法恢复的草稿保留原快照。

“备份工作区”导出一致性快照，含宿主库、工具数据和校验索引。“恢复工作区”先保留当前数据到 data/host/backups，再导入，成功后退出，下次启动加载。操作前等待全部作业结束。高版本数据或损坏快照会拒绝启用。

外部源文件与自选输出目录需另外迁移。整包迁移时正常退出后复制整个便携目录。可写数据根不可用时程序提供重新选择位置的入口。源码开发迁移参照 development.md。

## 最终设备检查

首版面向 Windows x64。请在目标电脑检查窗口拖动、缩放、最小化、Snap、系统文件对话框及多屏缩放。检查工具运行、草稿重启、安装移除和备份恢复。自动验证范围及尚待人工检查项目在开发仓库的 R2 报告中记录。
