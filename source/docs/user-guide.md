# ModynToolbox 使用说明


## 1.6.0源码工具集

当前图片压缩1.3.3、视频裁剪1.4.2、文本翻译1.1.5，蓝色公共壳；上一公开1.5.0附带的版本仍见发布记录。点击工具名称或正常重启主区默认进入已安装兼容最新版，复用已有新版会话，不必按加号。旧会话分支仍保留原版本和草稿，点击分支可继续旧工作，不强制搬运未知字段。运行中复制新包不会突然切走当前任务，下次点击工具名称即用新版；恢复浮窗保留原会话。

文本翻译默认纯本地中英互译，输入文字点击翻译即可，不需网址/Key/系统Python/额外模型下载。原文不联网发送；选择“翻译方式”才可切换公共在线或自建服务。旧会话明确选过的在线方式保留。模型会占用磁盘和执行时内存，运行时CPU最多4线程，机器翻译可能有错。工具安装要求宿主1.5.0及以上。

视频使用同一条时间轴：两端拖柄选择导出区间，蓝色竖线定位播放位置；也可用“设为起点/终点”或下方行内秒数精确输入。最小主窗仍能看到添加视频/时间轴/导出，小窗导出设置按需展开；结果默认收起以保留编辑区，点击输出结果查看。快速截取保留先准备并确认真实区间的流程，原文件不覆盖。

工作区默认轻留白，设置可切贴边。文件校验/JSON/批量重命名不默认分发，旧数据及源代码保留。

## 打开与日常操作

完整便携目录中双击 ModynToolbox.exe。项目开发目录中双击 Open-ModynToolbox.cmd 可打开最新本地完整包；本地构建不等于GitHub正式发行。便携包保留同级app、tools、runtime、data。便携运行不要求安装 Python。

在左侧搜索并选择工具，主区显示该工具的输入、参数和处理按钮。工具较多时显示分类筛选。搜索支持工具名称、描述、分类和关键词。

每个工具右侧的 ＋ 新建一份空白会话，原会话继续保留。单会话时左侧紧凑显示，创建第二份后展开树形分支。点击分支切换，父工具名称回到最近使用的会话。Ctrl+N 可在左侧为当前工具新建会话。折叠展开状态会保存。

右键工具或会话，管理重命名、并排、保存草稿、独立窗口、收回和关闭。按住名称拖动，移到主窗口外松开会成为独立窗口。拖父工具时移出最近选中的会话。Esc 或在主窗口内松开取消拖出。浮窗关闭按钮收回会话，左侧 ↗ 表示它在独立窗口中，点击可唤起。

软件名称和说明分两行显示在顶部，浮窗第二行显示工具与会话名。主工作区集中显示工具输入、参数、动作和结果。

## 兼容工具说明（部分已不默认分发）

| 工具 | 用途和规则 |
|---|---|
| JSON | 校验与格式化 UTF-8 文本，最多 5 MiB，保留数字、字符串转义和重复键的原始标记。错误给出定位，重复键给警告。 |
| 图片压缩 | 静态 JPEG/PNG/WebP，默认 WebP 质量 80，最长边 0 表示保持尺寸，避免放大。PNG 无损，透明图转 JPEG 用白底，应用 EXIF 方向并移除元数据。最多 500 张，单图 50 MiB、4000 万像素。 |
| 批量重命名 | 先预览，再确认执行，支持前后缀和编号规则。输入或规则变化后重新预览。可尝试撤销最近成功批次，异常中断后明确执行恢复。最多 2000 个文件。 |
| 文件校验 | C++ 独立工具，分块计算 SHA-256 / SHA-512，最多 2000 个文件，结果可复制或导出，支持取消。 |

图片输出目录留空时存到 data/tools/image/exports，指定目录时存到该目录。已有文件会使用编号区分。取消保留已经完成的输出。源图保持原样。

重命名处理期间不要删除工具数据中的计划和 journal。源身份、内容或目标变化可能导致拒绝执行或撤销，应先查看逐项结果和恢复记录。

文本超过 32768 个 UTF-16 码元时，界面显示只读预览并提示。完整数据仍保留，用于处理、复制和导出。要编辑大文件，可在外部编辑后重新载入。JSON 输入上限仍为 5 MiB。

结果导出在后台执行，采用临时文件原子提交。确认覆盖已有导出文件后才保存。可以通过运行记录查看状态，提交期间等待完成。

## 运行记录与设置

顶部活动入口只在运行、排队或存在未读失败记录时显示。管理菜单始终可以打开运行记录，查看动作、会话、状态、计数、输出位置或取消仍可取消的作业。记录最多保留最近 500 项摘要。

管理菜单的设置包含字体大小、界面密度、重批处理并发数、新会话默认保存草稿及处理结束后定位结果。默认全局最多两份作业、重批处理一份，同工具串行执行。重批处理可调整为两份，应结合本机内存使用。

## 安装、升级和删除工具

在“工作区管理 → 工具包”选择包含 manifest.json 的完整工具包目录。安装会校验包内容与接入规范。工具名称入口及新会话使用已安装兼容最新版，已有旧会话分支固定原版本。不会自动联网下载未安装的版本。

移除前关闭引用该版本的会话并等待作业结束。移除工具程序保留 data/tools/<tool_id> 中的数据。退出软件后，也可直接删除 tools/<tool_id> 的程序文件夹，下次启动撤下入口。运行时手动删除的缺失包可刷新识别，原会话输入继续保留，重新安装相同版本后可继续。

仅安装自己认可来源的本地工具。工具具有当前用户系统权限，文件摘要用于检查内容完整性。

## 草稿、数据和迁移

默认保存参数与布局。左侧会话右键菜单勾选“保存本会话输入草稿”后，正文和文件列表才进入 data/host/state.sqlite。新会话默认值可以在设置中调整。恢复不自动执行作业。文件缺失会保留引用并提示，可移除缺失项后重新添加正确路径。无法恢复的草稿保留原快照。

“备份工作区”导出一致性快照，含宿主库、工具数据和校验索引。“恢复工作区”先保留当前数据到 data/host/backups，再导入，成功后退出，下次启动加载。操作前等待全部作业结束。高版本数据或损坏快照会拒绝启用。

外部源文件与自选输出目录需另外迁移。整包迁移时正常退出后复制整个便携目录。可写数据根不可用时程序提供重新选择位置的入口。源码开发迁移参照 development.md。

## 最终设备检查

首版面向 Windows x64。请在目标电脑检查窗口拖动、缩放、最小化、Snap、系统文件对话框及多屏缩放。检查工具运行、草稿重启、安装移除和备份恢复。自动验证范围及尚待人工检查项目在开发仓库的 R2 报告中记录。

## UI-R5 公共快捷入口

工具库右侧刷新按钮或 F5 重新读取工具目录，旁边数量为当前可用工具数。Ctrl+K 聚焦工具搜索。侧栏底部可直接打开会话、运行记录和设置，Ctrl+, 打开设置。工具包安装/移除及备份恢复位于工作区管理。数字参数右侧上下箭头可步进，键盘方向键也可调整，达到上下限时相应箭头减弱。


## 视频裁剪（1.2.0起）

工具库选择视频裁剪，导入一个视频并等待分析。拖动区间手柄或输入起止时间，必要时先播放检查。精确裁剪默认较高画质、原尺寸；要减小体积可选均衡/较小文件和较低尺寸。快速截取需先预览调整后的区间，再确认导出。

默认另存到源目录下ModynToolbox Exports，同名自动编号，原文件不覆盖。完成后打开输出文件或目录。多个视频使用工具旁加号开独立会话，离开时暂停预览，后台导出继续。启用草稿后重启会重新检查源视频再恢复选段。

当前视频工具1.4.2需要宿主1.6.0及以上（旧视频包维持其声明的最低宿主版本）；旧1.2.0工具包按旧兼容要求运行。下载完整便携包即可使用，独立视频工具包也可解压到兼容宿主tools目录后刷新。


## 窗口、开机自启动与重复打开（DS-1）

关闭按钮悬停显示实心红底白叉。主窗关闭仍按既有保存/作业规则退出；工具独立窗口关闭仍收回会话，不结束整个工具箱。

在侧栏“设置”中勾选“开机自启动（登录 Windows 后）”，点击“应用”后生效；取消勾选并应用即可移除。默认不添加启动项，不需要管理员权限。启动打开当前程序、当前工作区及其工具目录，不自动重新执行旧作业。设置取消不改变系统启动项。Windows启动应用设置/组织策略仍具有优先权。

自启动属于当前电脑/Windows用户，不随工作区备份迁移。移动或换用新的便携目录后，在设置检查注册路径，必要时点击“改用当前程序”并应用。删除整个程序前先取消自启动；仅删除工具包不改变工具箱启动项。同名非本程序管理的快捷方式不会被覆盖。

正常使用同一Windows用户/登录会话只保留一份主程序；再次双击唤回已有主窗，最小化时恢复，最大化状态保留。已有实例暂时无响应时说明原因，不另开一份争用工作区。登录自启动遇到已有实例则静默退出。工具浮窗、后台进程和浏览器进程可以有多个，这是独立工具架构的正常行为，不代表重复打开了整个工具箱。

旧版程序没有新的唤醒机制，首次升级请先正常关闭旧窗口，再打开新版本。再次打开另一目录的新版不会自动切换当前程序和工作区；需要切换时先退出当前主程序。

## Windows下载安全提示

如果显示“Windows已保护你的电脑／发布者未知”，这是SmartScreen对下载文件的发布者/信誉检查，不能仅凭该提示认定文件有毒，也不能保证文件绝对安全。当前签名状态见随包signing-report.json；没有正式证书时发行会如实保持未签名。正式签名可确认发布者身份，但新文件仍可能告警，自签名或EV也不保证免提示。请从项目GitHub Releases下载并核对SHA256；项目不会关闭系统防护或自动解除下载标记。进一步改善需可信签名身份或Microsoft Store上架，不把这类提示当作可以靠UI隐藏的应用弹窗。
