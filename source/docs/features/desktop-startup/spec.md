# DS-1 桌面启动与窗口操作增量

2026-11-15。用户本轮明确要求分析、设计并直接优化三项，连续本地实施已授权；不发布、不上传、不默认启用自启动。

- F1 主窗和工具浮窗关闭按钮悬停为不透明红底白叉，按下稍深，普通状态保持现有外框。
- F2 设置提供开机自启动开关，默认关闭，实际语义为当前用户登录Windows后打开当前程序/工作区；应用才写入，取消不改变，失败明确说明。不需要管理员权限，不随备份/复制工作区自动启用。
- F3 同一Windows用户/登录会话正常使用只启动一个主程序，跨目录/版本副本同样防重开；重复手动启动唤回主窗，重复登录启动静默退出。已有数据目录锁继续保留。
- F4 工具浮窗、多会话、独立后端和工具完整前端不变；显式自动化、headless验证及单工具开发runner可隔离运行，不唤醒用户窗口。

验收：原生按钮渲染；隔离Startup文件夹实际创建/读回/禁用/路径引号/取消/错误；真实多进程竞争、唤醒/静默、异常结束后重启；现有回归及本地完整包。真实注销/重启与前台焦点不在本轮无人值守测试中执行。
