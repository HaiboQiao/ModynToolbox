# 实施方案
沿用C++20/Qt Widgets公共壳和工具自有HTML/CSS/JS，公共语义主题Token替换蓝色；Logo改色不改图形。工具CSS各自拥有，不由宿主注入。
视频页面采用可收缩预览、单轨范围+独立播放头、紧凑行内精确输入，主区域/导出设置响应式；保留现有probe/prepare/export协议和快速截取确认。
翻译选Argos公开中英模型+CTranslate2 INT8 CPU+SentencePiece，独立工具build脚本还原锁定PyPI轮子与模型，完整包附来源/许可/哈希，运行完全断网；分句有界分段，取消检查和部分结果沿用SDK。
焦点使用鼠标点击不抢Tab焦点的按钮策略，仍保留TabFocus键盘指示，不去掉所有focus样式。
宿主1.5.0，内置image 1.3.1、video 1.3.6、translate 1.1.3；旧版本不覆盖。发布先全量Debug/Release/冻结SDK、实际离线双向、视频时间轴/小窗渲染和鼠标/键盘焦点回归，再干净源提交打包、全部附件公开复验。

实际模型包293.78MiB超过原256MiB上限：通用工具安装上限提高到512MiB，仍保留4096文件/完整性/路径限制，本地翻译要求宿主>=1.5.0；其他工具/旧包规则保持。此项通过真实完整模型包安装验证。
