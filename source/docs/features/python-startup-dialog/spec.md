# Python 初始化弹窗专项

侧聊用户要求检查python.exe 0xc0000142且经常两次弹出。仅修复工作进程/故障测试路径，不接续主线程任务。

发现：budget测试在128MiB作业组内创建20个Python，只检查Popen数量即返回，清理可落在DLL初始化；tree测试在子进程就绪前发布PID，宿主崩溃测试随即强制清理。截图不能确定具体哪个PID，也不能把恰好两次推断为固定重试次数。

方案：测试子进程主动写就绪标记，20个同时存活后协作退出；budget单独512MiB/15秒，独立memory故障用例仍128MiB。tree发布PID必须在就绪后。WorkerHost仅本进程设置SEM_FAILCRITICALERRORS并继承到子进程，保留退出码/失败与WER；真实C0000142在工具箱中明确诊断。不动系统注册表、全局Python或生产资源限额。
