# 方案

缩放：原生命中层仅首次/原生句柄变化配置，不在每个resize反复设置透明度和Z序；浏览器父窗口/Bounds/Visible/屏幕位置分别去重，布局事件合并；原生拖动尺寸循环中直接同步Bounds，不等待0ms定时器，保留真实move通知。增加调用计数与原生连续尺寸/截图验证，物理拖动帧观测单列。

界面：分隔从sidebar边线+3px默认handle改为单细线，1px把手利用Qt扩展命中区；工作区轻留白或贴边两种，淡边不带厚圆卡片。翻译页独立设计双文本区、单行主要操作、折叠服务配置。

工具集：通用toolset默认停用列表供构建/打包使用，不在宿主按工具ID限制UI。只读检查运行/作业，SQLite备份后按确切三个ID移出活动会话，安装包转存.local/disabled-tools，data保持。

翻译：参照LibreTranslate开放接口和成熟翻译交互，自己实现轻量工具；不嵌整套Pot桌面app、不打包其GPL代码或LibreTranslate服务。MyMemory为可直接试用的公共API，并非开源引擎，有额度/500-byte单段限制；LibreTranslate自建支持本地服务，是否具备中英取决于模型。Key仅环境变量。测试先本机HTTP协议夹具，再少量公共示例真实互翻，不能把夹具算译质验证。
