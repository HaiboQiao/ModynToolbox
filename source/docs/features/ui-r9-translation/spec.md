# UIR-9 稳定缩放、工具精简与翻译

用户授权直接修复缩放闪烁、优化分隔与审美、删除三个无用工具；翻译第一版确认先在线/自建，保留离线扩展。保留工具作者完整前端、独立后端、固定版本、原数据/作业；仅本地交付。

F1连续缩放中减少重复原生样式/Z序/浏览器父窗口及可见性设置，尺寸按最新值更新；分离收回不重载、无新作业。F2单细分隔线、Qt保留扩展拖动区；默认轻留白10px/淡直边，设置可选贴边，工具仍拥有内部布局。F3默认工具集不再构建/打包文件校验、JSON、重命名；开发安装目录移出发现路径，已有会话元数据备份后移出活动列表，数据和源码保留便于恢复；不永久删除历史发行包。F4独立翻译工具支持中英双向/源语种自动判断、交换语言、复制/导出、取消、错误说明；自有完整前端+Python标准库后端，支持MyMemory公共在线及LibreTranslate标准服务（可本机部署），未来离线引擎只改工具适配。任何外发均用户点击，不自动上传正文；不在草稿/作业参数中放APIKey，需Key服务从环境变量读取。
