# ModynToolbox 界面设计与功能约定

2026-11-11，UI-R5。面向维护宿主和开发独立工具的人员及 Agent。本文是新增界面的设计入口，实际支持的 UI 字段仍以 shared/protocol 和 docs/tool-development.md 为准。

## 产品用途与布局

本地工具工作台用于查找工具、建立独立会话、执行文件或文本处理、查看结果和管理工具包。主要用户希望快速处理工作，同时保留多个工具的输入与运行状态。

标题栏负责品牌、当前窗口身份及系统窗口控制。左侧负责工具发现、分类、会话树和公共功能。中央负责当前工具的输入、参数、执行、结果与状态。浮窗沿用品牌、控件和业务页面；关闭浮窗收回已有会话。中央区域不增加常驻公共搜索、公共页签或重复工具目录。

## 公共功能与使用路径

| 需求 | 当前入口与行为 | 设计理由 |
|---|---|---|
| 找到工具 | 侧栏搜索，Ctrl+K 聚焦，清除按钮恢复列表；多分类时出现分类框 | 工具增多后仍能快速定位 |
| 新增工具后发现 | 工具库标题右侧刷新，F5；数量徽标展示当前可用工具数 | 放入目录后可以立即核对接入结果 |
| 同一工具多份输入 | 工具右侧加号，新会话显示为树分支；Ctrl+N | 保留原输入，避免重复开整个程序 |
| 独立使用与对照 | 拖出名称分离窗口，关闭后收回；右键菜单提供并排等操作 | 适应多任务，同时减少常驻按钮 |
| 找到已打开会话 | 侧栏底部“会话”，复用会话选择菜单；Ctrl+Tab 切换 | 工具列表较长时跨工具定位 |
| 查看运行与失败 | 侧栏底部“记录”，运行中/未读错误时显示活动提示 | 让用户能找到运行历史和失败原因 |
| 调整使用习惯 | 侧栏底部“设置”，Ctrl+, | 设置字号、密度、并发和草稿策略 |
| 安装、移除与迁移 | 工作区管理中保留工具包、备份和恢复 | 低频或需要确认的操作集中管理 |

本轮将既有会话、记录、设置提升为直接入口，增加工具库数量与刷新。安装/移除、草稿、历史、备份和调度复用已有实现。

## 后续功能取舍

以下是后续设计候选，尚未实现，不作为本轮可用能力。

| 条件 | 可增加能力 | 验收重点 |
|---|---|---|
| 工具数量明显增加且搜索不足 | 收藏/置顶，以及“全部/收藏”筛选 | 只保存 tool_id；缺失工具保留偏好；筛选不关闭会话 |
| 反复执行相同参数 | 每工具命名参数预设 | 与工具版本和字段规范绑定；不默认保存文件正文；未知字段不覆盖默认值 |
| 长任务多、历史定位困难 | 在现有运行记录内增加状态筛选和重试入口 | 重试前复验输入路径、权限和写入确认；避免重复写文件 |
| 新工具开发与分发更频繁 | 工具管理内显示协议兼容、包版本和诊断结果 | 展示具体可恢复原因，安装仍按暂存/校验/启用语义 |

优先观察真实使用后增加能力。每个新增常驻入口都应对应高频任务，有可发现的名称、状态和反馈。避免装饰性仪表盘、无数据通知、重复工具网格和占据工具工作区的公共栏。

## 品牌与色彩

采用用户选定的 B 标识，工具箱轮廓结合 M，紫白配色。正式资源位于 app/resources/logo.png 和 modyn.ico，来源为本项目已选生成稿。ICO 包含 16/24/32/48/64/128/256px 图层，PNG 保留为母版，ICO 通过 Qt 资源内嵌到宿主，Windows RC 内嵌到根启动器和 App exe。主窗、浮窗和应用对话框统一使用同一标识。

延续浅色雾紫。背景 #f4f3fa，侧栏 #f2effc，面板 #ffffff，正文 #292735，辅助文字 #6c687c，边框 #ddd7e9，强调 #7054d8，选中 #ece7fd。状态文字需要同时说明含义，成功/失败不只依靠颜色。重处理主动作使用紫色实心；文件选择、移动、导出等次动作使用白底细边框；窗口与刷新使用轻量图标按钮。

## 字体与尺度

下列尺寸均为 Qt 逻辑像素，系统 DPI 自动缩放。不要把系统像素写进工具业务代码。

| 项目 | 默认规则 |
|---|---|
| 正文与输入值 | 14px，可在设置中选 12–18px |
| 字段名、说明、次要入口 | 正文字号减 2，默认 12px |
| 区段标题 | 正文字号，600 字重，短标题 |
| 品牌名与说明 | 两行，3px 行间距，整体垂直居中 |
| 常规控件 | 最小内容高度为正文字号+6，标准上下留白 7px，紧凑 5px，边框 1px |
| 按钮横向留白 | 12px，文字自然宽度，避免固定宽度截断中文 |
| 单行输入横向留白 | 10px，数字框右侧预留 36px 给步进区 |
| 数字步进区 | 宽 28px，上下两区使用清晰箭头，达到边界时减弱箭头 |
| 控件圆角 | 7px；工具面板 12px |
| 页面和面板内边距 | 页面 24px，面板 20px |
| 间距 | 大区块 12px，字段组 8px，字段名到输入 5px |

标准字号14下常规按钮和输入框约36px高，字号18下约40px。采用最小高度和自然排版，为字体保留余量。紧凑模式统一压缩留白，不能靠单个按钮单独缩放文字达成。

## 组件与交互状态

- 按钮文案使用动作，例如“添加文件”“导出结果”。同一操作在不同工具中采用同一用词。一个处理区域突出一个主要动作，多动作的业务差异通过明确名称表达。
- 普通、悬停、按下、焦点、禁用均由统一 Theme 管理。主动作的禁用状态必须能辨认。危险操作使用明确确认文案，默认焦点避开破坏性提交。
- 数字参数使用 UiSpinBox，保留 QSpinBox 原生范围、输入验证、键盘、鼠标步进和辅助功能。箭头由公共组件绘制，避免原生主题与 QSS 混合后空白。已有 number 字段自动获得该控件，工具不用自行绘制。
- 下拉选择使用 UiComboBox。长选项采用自适应尺寸或可滚动布局，不能压住箭头。复选框旁的说明表述启用后的实际效果。
- 输入提示说明格式、单位和默认值，例如“0 表示保持尺寸”。输入失败时给出原因和恢复方法，禁止只显示错误颜色。路径字段提供选择入口。
- 空列表说明下一步操作。处理中保留输入归属并显示当前动作，取消沿用工具声明的可取消策略。完成后展示结果数量、文件位置或可复制内容。
- 表格标题、行距和选中色使用公共组件。文件动作靠近文件列表，结果动作靠近结果。大量内容在工具面板内部滚动，执行与状态按既有渲染器保持可达。
- 图标使用共用绘制/资源，不能依赖某个字体恰好包含符号。图标按钮提供 tooltip 与 accessibleName。所有操作可通过键盘或菜单访问。

## 独立工具页面组织

依次组织输入、参数、执行、结果与状态。简单文本工具可采用上下输入/输出；文件工具可采用左输入、右参数，窄窗口由已有 ToolPanel 调整。说明应短，容量、覆盖原文件、输出位置等影响决策的限制就近说明。

使用 integration/ui.json 的 files/text/fields/actions/output_text/output_table/image_preview/status。number/choice/range/boolean/directory/text 交给公共渲染器。字段名标明单位，默认值对第一次使用合理，条件参数通过 enabled_when 表达。不要在工具 UI 中复制品牌标题、公共搜索、版本脚注、侧栏或会话条。

业务核心与后端依赖继续独立。新增工具只提交自己的目录、协议适配和 UI 描述，既有公共组件支持的范围内自动继承此规范。新的组件类型需同步 renderer、校验、Schema、文档与对应交互验证。

## 维护入口与验收

颜色、密度和字体集中 app/ui/theme；图标、选择框和数字框集中 app/ui/components；窗口品牌集中 ChromeWindow；资源集中 app/resources。禁止每个工具追加一份 QSS 或在业务后端计算宿主界面尺寸。

修改后至少检查默认与最小窗口、标准/紧凑、12/14/18字号、中文长文案、空/运行/完成/错误/禁用状态。数字框需要检查鼠标上下、键盘、上下限和焦点。查看真实 Qt 渲染截图，记录离屏与目标设备验证的各自范围。保持 task/checklist/STATUS/worklog 同步。

当前无可调用 Context7，相关布局、数字框子控件和资源接入核对 Qt 6.8 官方资料。[Qt 样式示例](https://doc.qt.io/qt-6.8/stylesheet-examples.html#customizing-qspinbox)、[Qt 资源系统](https://doc.qt.io/qt-6.8/resources.html)


## UI v2 视频页面

2026-11-12，视频类工具通过video_editor公共控件接入。采用深色预览承载区与雾紫外围，未播放时明确显示预览提示；不以白色空白冒充画面。预览与参数采用2:1空间权重，窄窗纵向排列。起终点采用明确时分秒毫秒输入，时间轴支持鼠标和键盘；输入时间时暂停，保留现有主动作、状态、字号和密度规则。元信息简短展示，复杂业务依旧在独立进程。

媒体角色与条件通过ui.json声明，规范见shared/protocol/media-v2.md。恢复/分析状态允许程序化更新区间，运行时禁止用户修改本次导出参数。结果区可打开输出文件和目录，大小变化明确相对完整源视频。


## EXT-1 通用接入增量（本地1.3.0）

UI v3支持动态/级联选项、显示名与固定值、搜索、compact、help/placeholder、advanced。独立工具采用新字段前读取docs/features/host-extensibility/design.md（从源码根定位），同步声明最低宿主1.3.0。旧v1/v2继续兼容。工具进程可声明max_processes（4–64，默认16），用户目录环境由宿主补齐，工具包目录变化自动检查，会话仍固定版本。实际证据见verification/EXT-1-host-extensibility.md。
