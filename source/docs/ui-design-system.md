# 当前UI设计与所有权
<!-- project-status: current -->

先读[项目背景](project-baseline.md)。本规范的强制尺寸/组件适用于公共壳和Legacy Qt控件；完整工具frontend拥有全部页面，主题仅建议，不要求相同布局/库/固定页脚。历史原文保存在[旧UI规范](history/gp1-before/ui-design-system.md)。

## 公共壳

蓝色B方案工具箱标识与清爽蓝白；标题栏放品牌/窗口身份与系统控制，左侧放搜索、工具、会话和公共入口，中央留给工具。主窗和工具浮窗复用ChromeWindow；浮窗关闭默认收回，不结束工具箱或重提作业。避免重复目录/搜索/页脚和装饰性仪表盘。

颜色由Theme集中：背景#f3f7fc、侧栏#eff5fd、正文#142238、辅助#61718a、边框#d5e1f0、强调#0866f5、选中#dceaff。关闭普通透明灰叉，悬停#e81123白叉、按下#c42b1c白叉，保留键盘焦点。

| Qt公共控件 | 当前建议 |
|---|---|
| 正文/字段辅助 | 默认14逻辑px，设置12–18；辅助减2，随系统DPI缩放 |
| 品牌 | 两行、3px行距，整体垂直居中 |
| 常规控件 | 标准上下7px、紧凑5px；按钮左右12、输入左右10；7px圆角 |
| 数字/下拉 | 公共UiSpinBox/UiComboBox，清晰箭头、边界/禁用状态与键盘支持；滚轮不修改参数，传递给父级滚动 |
| 布局 | 默认侧栏190，宿主工作区0额外留白；工具自行决定内容留白（内置工具12、窄屏10），主要间距12；内容从顶部自然排列 |

不要散落新QSS/硬编码或在工具后端计算宿主尺寸。空/运行/成功/错误、禁用、焦点、hover/pressed均检查；参数错误有原因，不能只靠颜色。设置说明不纵向拉伸，多余空间在按钮上方。

## 工具完整页面

工具按真实工作设计结构：编辑器、播放器、图表、表格、规则与预览可各不相同。HTML/CSS/框架由作者维护，宿主不重置DOM/CSS或按tool_id增加页面代码；可选择接收主题/字号/密度建议。工具前后端只经契约通信。

建议清晰动作文案、适当文字边距、可达的取消/结果/错误与键盘焦点；避免无意义重复品牌。风格协调不意味着必须使用固定控件树。工具自己声明/实现响应式，按窄窗和较大字号验收；宿主只限制承载视口与通用安全/容量。

## 检查与兼容

修改公共控件按[变更规则](change-policy.md)判断会影响哪些页面和BC，真实运行/截图不能用编译代替。默认/紧凑、12/14/18字体、最小/默认窗、中文长文案及控件状态按涉及范围检查；物理DPI、IME和多屏单列证据。

旧ui.json字段/渲染器规则继续适用于旧包，不能反向限制新frontend。完整接入见[开发指南](independent-frontend.md)。

## UIR-7 交互默认值

UIR-8窗口外框本身无布局外圈；8逻辑px边缘只作原生输入命中区，位于内容上方、极低透明度，不挤占视口，最大化/全屏隐藏。嵌入浏览器不能覆盖命中区。Windows10兼容清单是该透明子窗口能力的运行条件。旧ToolPanel外层卡片边框和圆角也移除，工具自身输入框/分区边界仍由作者决定。

内置完整工具由各自frontend/base.css维护：文本/数字/下拉/多行输入的焦点只改1px边框颜色，不叠加粗外圈；按钮等仍保留1px键盘焦点提示。各自interactions.js阻止数字/范围/选择控件的滚轮改值并滚动最近可滚动祖先/页面，保留焦点和键盘/点击。新工具建议沿用这种交互，作者仍可自行实现，宿主不注入这些规则。禁止为了滚轮保护而blur输入框、让页面滚不动或隐藏必要焦点。


## UIR-8 交付路径验收

工具包升级不等于旧会话自动升级。当前旧会话的侧栏显示“旧版会话 · 打开新版”，说明固定版本与可用版本，点击新建最新版会话，原会话/输入保留、不迁移未知字段。该提示属于导航，不进入工具页面。

加载阶段可短暂显示“校验工具包/加载界面”，就绪即撤去，不占用永久公共标题/页脚。缓存默认2闲置页/5分钟；设置0–5页、1–10分钟，0为积极回收，提高页数有明确内存成本提示。验证应使用实际开发入口和旧/新版会话，并区分首次、热切换和超额冷开；原生缩放必须查到真正最上层子窗口，Web输入使用后台模式的原生可信输入验证，不能只测根窗口或dispatchEvent。


## UIR-9 当前工作区与缩放

用户重新要求适量层次，默认采用轻留白：工具承载区四周10逻辑px、极淡直线边框，不加大圆卡片、阴影或公共业务控件；设置可改为贴边0留白。这是可调整的公共承载外观，不向完整工具页面注入CSS。左侧删除重复边线，分隔把手宽1，利用Qt扩展命中区保持可拖动，避免默认3px背景条。

连续缩放不反复设置透明输入区样式/透明度/Z序；浏览器父窗口、可见性、位置与Bounds分开按变化更新，布局事件合并。DPI由Qt实际比例驱动WebView2 RasterizationScale，不能把二者不同步造成的视口/字号差异当普通边距。隐藏时只更新可见性，保留迁移停放保护。

新增翻译工具采用自己的完整双文本页：一行语言操作、折叠服务设置、明确的翻译/取消、复制/导出和状态。保留细焦点、下拉滚轮不改值、窄窗纵向排布，明确在线服务与发送时机，不复制公共壳品牌/搜索/版本页脚。

## UIR-10 蓝色与动作焦点

用户2026-11-17明确选清爽蓝白，替代早期雾紫。公共accent #0866f5、selection #dceaff、background #f3f7fc、text #142238、border #d5e1f0，工具可自主采用，宿主不注入CSS。动作按钮不表达持续选中，鼠标点击弹窗返回不画键盘焦点；Tab仍可见focus。视频/翻译各自拥有完整响应式布局，不用宿主模板。
