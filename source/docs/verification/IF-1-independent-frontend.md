# IF-1 完整工具前端：实现与验证

2026-11-15。本地宿主1.4.0，日常五工具包1.2.2。用户授权连续实现原始“宿主是箱子、工具拥有完整前端”的目标。本轮没有推送GitHub、创建标签或正式发行；公开版本仍为1.3.0。保留UI-R6与全部旧版本包。

## 交付内容与职责

宿主保留C++20/Qt Widgets外框、工具发现、导航、版本、会话、浮窗、调度、数据与通用桥。ToolSurface替代Workbench对ToolPanel的直接依赖；旧ToolPanel继续兼容UI v1/v2/v3。WebToolView与Windows WebViewSurface承载工具自己的静态Web页面；不解析业务DOM，不按工具ID增加控件，也不注入宿主CSS。

工具在frontend/拥有HTML/CSS/JS或框架产物、全部布局、业务控件、预览、动作/状态位置与响应式。core/和后端仍独立；integration/只接协议。图片前后对照、重命名规则与结果、校验表、JSON双编辑器和视频播放器/时间范围已分别实现，公共示例样式是工具自行持有、可替换的文件。

桥提供版本化握手、主题建议、文件授权/媒体范围流、作业提交/查询/取消、剪贴板/导出、窗口位置及不透明检查点。每会话非终态作业与32项幂等回执、分片和容量/速率边界由宿主管理。控制消息256KiB，大payload最多16MiB，媒体不通过整文件Base64。为兼容已有5MiB JSON输入，检查点从原提案1MiB调整为16MiB，工作区数据库总状态仍受64MiB上限。

隐藏页面先请求新检查点，成功且没有作业时回收；退出同样协商。草稿关闭不跨启动保存正文；浏览器缓存不是唯一业务状态，工作区备份排除ui-profiles/ui-transfer。不同工具版本使用独立浏览器组；同工具同版本共享组，因此同组故障可影响多个会话。可信本地工具不是权限沙箱。

改名工具修改文件/顺序/规则后旧计划不可确认，需重新预览；处理期间相关输入锁定。工具作者可自行采用这些业务规则，不由宿主布局模板决定。

## 冻结宿主后接入验证

最终宿主EXE SHA256：`b0848293db84849029a8bfd1c6f09cd6ff92f79d4795b48b4504f387c3236996`。

先冻结app实现（不含测试）、CMake、桥SDK和EXE，再从导出的不含app源码SDK在独立目录构建两个新工具：Vanilla HTML/JS + Python统计工具、Vue + C++字节转换工具。宿主运行期间复制完整包，自动发现并真实执行，包含会话/窗口/编辑检查共20步。验证后全部冻结哈希一致，没有为了这两个工具修改宿主。

本机一次构建0.439秒/8.355秒；复制0.074秒/0.038秒；宿主接入验收17.204秒，其中包含两次显式7秒目录发现等待。这是已准备依赖下的观测，不把首次安装依赖或业务开发时间算成“几秒开发完”。源码在examples/independent-frontends；完整记录见IF-1-evidence/frozen-receipt.json、freeze.json及两张真实截图。

新增工具通常只需：完成自己的核心和前端；适配通用桥/后端协议；构建完整工具包；复制tools/<id>/<version>。已有能力足够时不改app。新增宿主级能力或协议变化仍需修改公共宿主，不能承诺宿主从此永远不更新。任意现成Qt/WPF原生窗口不是零适配内嵌路线。

## 验证中发现的问题及修正

- 初始下载SDK包截断：保留失败记录后重试，最终按锁定SHA256核对，不使用不完整依赖。
- 初始原型隐藏窗口截图不完成：改用不激活、屏幕外原生窗口；Qt offscreen仅用于旧界面回归。
- 媒体路径和前端使用同一虚拟主机映射导致图片无法显示：分离媒体授权域，以受限范围IStream服务，真实naturalWidth检查通过。
- Qt+Web合成截图在COM流仍锁定时为空：延后合成并统一DPR；最终实际完整截图已目视检查。
- 独立C++首次构建路径过长：缩短私有验证目录；Python独立适配缺少core路径：仅在工具自身修正，未靠宿主特判。
- 固定引擎便携启动失败：对包内runtime路径做canonical/native规范化，并补充HRESULT诊断；最终观察到包内引擎且48步通过。
- 新增窄窗测试使用已经被宿主按设计回收的旧页面指针，Release/Debug出现测试进程访问异常：测试改为通过会话重新取当前页面，并在回收前断言结果。修正后的全量双配置均通过；未回避失败记录或以旧成功结果代替最终结果。

## 使用、升级与未覆盖范围

开发目录双击Open-ModynToolbox.cmd打开latest记录指向的本地完整包；Run-Dev.cmd运行源码。当前包位置以.local/releases/latest.json为准。新的五工具版本是1.2.2，旧会话仍锁旧版本；点击工具旁加号新建新版会话查看完整前端，不强转旧快照。

正式发布仍需用户明确指令，届时重新按release-policy固定源码、构建、验证、上传源码与发行资产。目前GitHub保持1.3.0，不能把本地1.4.0称为已公开版本。

本机受限环境测试不等于另一台真正没有WebView2/开发依赖且断网的电脑。真实中文IME、多屏物理DPI/Snap、任务栏、完整键盘焦点与可访问性、视频听感/复杂编解码/4K、长期洪泛/渲染卡死、真实跨机备份与跨Agent接手保留单独验收，不用后台脚本冒充完成。当前开发效果和核心自动验收已完成。
