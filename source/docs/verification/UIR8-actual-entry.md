# UIR-8 实际使用路径复查与修复

2026-11-15，本地宿主1.4.0、工具包仍1.2.3。用户明确反馈五项优化除边距均无效果并不满意边框，确认实际使用Run-Dev/dev.ps1/VSCode。没有发布/推送，没有改写真实开发数据库、旧工具包或用户正文。

## 为什么上次交付不能代表用户效果

- **版本路径遗漏已确认**：只读开发工作区版本元数据，五个已有会话都固定1.2.2、完整Web前端。焦点、滚轮和工具自身内距修复在1.2.3里；宿主源码更新不会改写不可变1.2.2。因此“宿主边距有变化、控件没变化”有直接证据。上轮把新包通过当成已有会话效果已改善，验收覆盖不完整。
- **缩放路径遗漏已复现**：用户Debug入口的私有测试，根HWND左/右/上/下返回10/11/12/15，但实际原生子窗口返回HTCLIENT(1)，遮挡根窗口命中。上轮仅发消息给根窗口无法证明用户能拖动边缘。
- **性能口径过窄**：当前修复前Debug+1.2.2旧会话条件下，JSON首开923ms、hash582ms、三次JSON返回49–51ms。说明UIR-7短距离热缓存已工作；原来Release的6.4–6.7秒不是所有点击的统一耗时，不能据此断言用户每种切换都已改善。两闲置页/60秒也不涵盖五工具持续切换或较长停顿。
- **可见边框来源**：UIR-7使用8逻辑px布局外圈避让原生子窗；工具1.2.2自身还有20px内距；旧Qt兼容面板还保留圆角卡片边框。它们叠加造成右侧像嵌了一块面板。

## 实际修复

1. **缩放与外圈一起修**：ChromeWindow内容布局0四周边距。8个原生输入边缘位于内容之上，以1/255低透明度捕获系统命中/按下，不挤占工具视口；最大化/全屏隐藏。测试核对真实最上层子窗、八方向、透明属性，覆盖真实Web页面的主/浮窗。保留标题拖动、系统关闭红色、最小尺寸及收回行为。旧ToolPanel公共外框改为无边框/无圆角；工具内部输入/上传区边界仍是作者自己的内容。
2. **补齐系统条件**：透明子窗口初次实测SetLayeredWindowAttributes失败87，进一步确认缺少Windows8+感知兼容清单。CMake仅增加向modyn_shell宿主及其测试传递app/resources/windows.manifest的Windows10兼容声明，不修改执行权限、测试集合或业务协议。加清单后真实属性和八向用例通过。官方要求见[Microsoft Using Windows](https://learn.microsoft.com/en-us/windows/win32/winmsg/using-windows#using-layered-windows)。不能把此前“可能Qt覆盖样式”的排查假设当作最终根因。
3. **明确升级入口，保留旧会话**：当前旧会话在侧栏显示“旧版会话 · 打开新版”，tooltip列当前/可用版本及保留说明。点击新建最新版会话，原版本与输入保留，不自动转移未知状态，也不篡改旧包。新版1.2.3继续使用其自有细焦点/滚轮处理；宿主没有向旧页面强制注入CSS/JS。用户不用切换开发入口或猜测+号含义。
4. **区分加载与切换**：校验与加载阶段有临时文字反馈，就绪立即撤去；保留包校验和懒加载。记录frontendValidationMs/frontendReadyMs用于诊断。默认两闲置页延长至5分钟，设置可调0–5页、1–10分钟，明确更多页占更多内存；0不保留。忙碌、并排、浮窗、失败检查点的保护不改。
5. **可信输入验证**：WebViewSurface::testInput仅在MODYN_BACKGROUND_VALIDATION模式开放三项DevTools输入/焦点白名单；不经生产工具桥、不发送全局键鼠。数字和下拉均通过浏览器生成的可信滚轮事件确认值不变、页面滚动、焦点保留，再用真实键盘输入确认仍能改值。焦点模拟使:focus真实成立并核对细线颜色/尺寸，不再依赖上轮仅强制CSS伪状态的证据。

## 失败纠正与范围

新增测试初次用了不存在的目录发现类，随后设置测试的UiSpinBox无Q_OBJECT导致findChild静态断言，均改为现有readPackages/QSpinBox后重新构建。透明输入区初次属性失败没有删除或放宽断言；补清单后严格通过。原测试保留，UIR-7“保留8px布局边缘”的断言按用户此次去外圈要求，替换为0布局留白及更强的实际最上层子窗口命中/透明检查。Windows10声明是本轮必要的构建关联修改，已保留before快照并记录范围理由，没有改测试收集或版本。

个别QTemporaryDir异步浏览器缓存锁和屏幕外几何警告保留在日志，没有清理用户浏览器或强删用户数据。真实鼠标拖拽手感、Snap、多屏物理DPI、另一台电脑、真实系统登录及IME仍单列设备验收；后台可信输入不等于全桌面端到端验收。

## 使用

继续原来的Run-Dev.cmd/dev.ps1 run/VSCode即可，Debug已经重建。正常退出旧进程后重开；已有1.2.2会话从侧栏“旧版会话 · 打开新版”进入1.2.3页面，原会话保留。频繁轮流使用五个工具可在设置把闲置页数改5，代价已提示；默认2页优先约束驻留数量。Open-ModynToolbox.cmd的本地latest也已更新，但不要求用户改入口才能用修复。
