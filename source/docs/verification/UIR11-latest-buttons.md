# UIR-11：默认新版入口与按钮排版

本轮用户请求：更新后不再手动按加号打开新版，改善公共和视频按钮的文字/大小。日期2026-11-18起，最终归档2026-11-19；本轮未发布、未推送，不改宿主版本号或已公开v1.5.0资产。

## 原因与修正

工具名称曾直接定位recentSessions，即使它锁定旧包；启动也直接恢复旧active。现在根节点鼠标/Enter表达“打开工具”，与旧会话分支的“恢复该会话”分开。默认按目录中已安装且兼容的最新版本匹配最近使用的新版会话，无匹配才新建；反复点击不不断创建。正常主区重启同策略；旧分支版本/UUID/草稿/结果归属不改变，浮窗恢复原会话，扫描不会切走当前工作/取消作业，不联网下载包。100会话上限仍保留。

按钮原先正文/小按钮字号与高度多处不同，短窗有25px高按钮，主按钮600字重又显粗重。现在字体为微软雅黑优先的无衬线，常规14px/20px行高/36px高，短窗32px高；次级13px/32px高，水平内边距常规14px/次级10px，常规400/主动作500字重。输入沿用同字体，不用加粗和扩大字体代替层次。播放头是专门图形控件，不套文字按钮尺寸。

三个工具各自在自己的CSS维护token，宿主没有注入或覆盖工具CSS。新私有包为图片1.3.2、视频1.3.7、翻译1.1.5；已安装旧包不覆盖。宿主保持C++ Qt/WebView2，后端算法/作业/协议不变。
