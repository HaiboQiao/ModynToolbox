# 媒体依赖

使用 dependencies.lock.json 锁定的 Gyan Windows essentials FFmpeg/ffprobe。实际构建含 GPL 组件，不能仅按 LGPL 标注。构建脚本将下载包中的完整 LICENSE、README 和依赖锁加入独立工具包的完整性清单。

FFmpeg 上游对应版本源码 https://github.com/FFmpeg/FFmpeg/tree/n9.0.2

构建发布者 https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2

正式对外分发前需整理实际构建全部组件的许可、构建配置与对应源码获取材料。本轮为本地开发验收，未授权公开发布。
